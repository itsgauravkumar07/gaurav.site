# Personal Portfolio Website

A modern, responsive **personal portfolio website** built to showcase my projects, skills, and GitHub activity. This project focuses on clean UI, responsive layouts, and production-ready frontend practices.

🔗 **Live Demo:** https://gaurrav-site.vercel.app/  
📂 **Source Code:** https://github.com/itsgauravkumar07/gaurav.site

---

## 🚀 Overview

This portfolio represents my work as a **Frontend Developer**, highlighting real-world projects, open-source contributions, and a strong focus on scalable, user-focused UI development. The design is minimal, performance-oriented, and optimized for all screen sizes.

---

## ✨ Features

- Fully responsive design (mobile-first)
- Clean and modern UI
- Project cards with live demo and GitHub links
- GitHub contribution activity section
- Optimized asset handling for production builds
- Smooth hover effects and transitions
- Accessible and readable layouts

---

## 🛠 Tech Stack

- **React** – Component-based UI development  
- **Vite** – Fast build and development tooling  
- **Tailwind CSS** – Utility-first styling  
- **React Icons** – Iconography  
- **Vercel** – Deployment and hosting  

---

## 📁 Project Structure

```txt
src/
├── assets/        # Images and static assets
├── components/    # UI components and sections
├── App.jsx        # Root component
├── main.jsx       # Entry point
└── index.css      # Global styles
```

---

## How to Run
 
- **Clone the repository** 
```txt
https://github.com/itsgauravkumar07/gaurav.site
```

-**Install dependencies**
```txt
 npm install
```

-**Start development server**
```txt
 npm run dev
```

-**Build for production**
```txt
npm run build
```

---

## 🌍 Deployment

The portfolio is deployed using Vercel, enabling fast global delivery and automatic builds on every push.
